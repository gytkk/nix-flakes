# Output format

For each repeated-work candidate, include:

- `Pattern:` short name
- `What repeated:` one sentence
- `Evidence:` concrete sessions, files, or user prompts
- `Best form:` `skill` | `automation` | `template` | `runbook`
- `Why:` why that form fits better than the alternatives
- `Priority:` `high` | `medium` | `low`
- `Next step:` smallest useful follow-up

When `Best form` is `skill`, also follow `skill-candidates.md` if a concrete proposal is needed.
