# Friction signals

High-confidence signals:

- The user says something was wrong, off, too long, too short, risky, or not what they asked for.
- The user repeats the request with stronger constraints.
- The user asks for a different reply style or action pattern after seeing a result.

Medium-confidence signals:

- The user trims scope after an overreach.
- The user clarifies formatting or delivery expectations.
- The user redirects from planning to action, or from theory to implementation.

Avoid over-reading:

- One minor clarification alone is not a durable friction pattern.
- Preference changes tied to one specific context may belong in a runbook, not a global rule.
