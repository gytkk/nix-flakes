# Output format

For each friction item, include:

- `Issue:` short summary
- `Evidence:` concrete message or behavior pattern
- `Preferred direction:` what the user actually wanted
- `Durable rule:` the behavioral correction to keep
- `Apply to:` `AGENTS` | `RUNBOOK` | `skill` | `habit` | `config`
- `Confidence:` `high` | `medium` | `low`
